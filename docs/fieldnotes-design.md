# WYQ / Fieldnotes

以个人数字刊物为方向的全站 UI 重构：暖纸色、墨绿文字、细线编号、衬线标题与克制的玻璃操作层。保留所有文章正文、已有工具、导出内容和生日模式，不使用虚构奖项或推荐背书。

## 页面分工

- 首页：原创线条观测装置（可切换三种形态）、最近文章、六个实验入口、个人介绍与阅读/写作/音乐近况。替换空白的“敬请期待”区块，保留可直接阅读的静态内容。
- 文章：统一导览、返回归档入口、清晰的标题与作者信息、受控正文行宽、页内目录及代码/图片功能。原先重复且未连接事件的侧栏由统一菜单和归档承接。
- 归档、分类、搜索：按照内容索引组织，以细分隔线替代重复的卡片边框。
- 六个工具：统一标题、工具切换栏与页面框架；编辑区、预览区、计时器和游戏按各自功能排版。天气、DNA 和 Markdown 输出画布保留原有独立主题。
- 图片生成器、404 与文章模板同样使用新框架。

## 维护

共享壳层模板放在 `templates/`，用 Node 自带模块生成，无安装步骤：

```sh
node tools/build-shell.mjs
```

`assets/css/edition.css` 负责新视觉系统，`edition.js` 负责本地时钟与观测装置交互，`orbit.js` 是构建和浏览器共用的原创几何生成器。原有文章和工具逻辑保留。修改共享壳层后运行构建；文章正文直接编辑对应 HTML。

玻璃延续细边、低不透明度偏好。新操作层使用墨绿配色，键盘焦点保留独立轮廓。装置只在指针移动/点击时更新，没有持续绘制循环；时钟每 30 秒更新，后台暂停；减少动态效果时停用动作。

版本：`edition.css?v=1`、`edition.js?v=1`、`orbit.js?v=1`、`search.js?v=7`；缓存 `wyq-v16-2026-09-12-fieldnotes`。

## 验收边界

`tools/layout-review.html` 是维护者使用的窄屏检查页，不进入网站导航或搜索索引。它用真实 Chromium iframe 的 320/375/390/768/1280 CSS 像素宽度检查响应式布局，可切换页面与主题。这不等同于真 iPhone/Safari、软键盘或设备 GPU 验证。

检查项：21 页共享导航与资源、8 篇正文和三个导出容器的内容保全、首页图形按钮、归档/分类/搜索、窄屏菜单和长文、工具状态与编辑、深色主题、减少动态效果与无障碍焦点。
