# iPhone Safari / Chromium 验收清单

基线：`main@6dd9ea4`，PR [#55](https://github.com/Riuip/my-book/pull/55)、[#56](https://github.com/Riuip/my-book/pull/56)。两次 PR 均未做浏览器视觉或真机验收；#55 明确遗留 Apple 图标缺失。

本轮方向：玻璃集中在导航、按钮和浮层；正文卡片保持清楚。Safari 使用 CSS 材质，Chromium 渐进增强背景折射；不承诺复刻系统级 iOS 26 渲染。代码排除 `CriOS` 等 iOS UA，验证 Chromium 分支请使用桌面 Chrome/Edge。

用一台真实 iPhone（优先日常使用的机型）跑 Safari，另用桌面 Chromium 对照。先正常模式，再深色、横屏、减少动态效果/降低透明度。记录设备、系统与浏览器版本；以下方框留给真机执行，不能用模拟逻辑检查代勾。

## 已修复的代码问题

- `liquid-optics.js`：原版对着色层使用普通 `filter`；本轮将单次位移用于 `backdrop-filter`，移除三通道 screen 合成。原线上 Chromium 截图已复现导航、按钮和卡片灰板。
- 正文卡片不再挂光学层；同屏 SVG 上限由 6/3 降至 4/2（精细/粗指针），嵌套控制不重复模糊，移除后重新插入的节点只保留一份装饰。
- `search.js`：粗指针设备横屏仍走搜索页；桌面弹窗增加关闭按钮、背景 inert、Tab 循环和关闭时取消延迟聚焦。
- `main.js` / `liquid-glass.css`：加入安全区与可视视口边界，工具页和目录跳转按导航实际高度留白。`enhancements.js` 中程序滚动尊重减少动态效果。
- 补全 4 个 PNG 图标；Apple 图标使用不透明底、不预切圆角；所有页面资源版本及 Service Worker 同步更新。缓存清理只作用于 `wyq-` 前缀。

## 本轮验证边界

- 通过：21 页统一资源版本与本地链接检查、166 处脚本引用/内联代码语法、205 条共享 CSS 规则/选择器解析、`git diff --check`。
- 通过：jsdom 模拟的光学生命周期、精细/粗指针滤镜上限、Safari/CSS 和实色分支、移除再插入、按压取消、搜索结果/关闭/焦点/Tab、横屏粗指针分流、菜单 Escape、目录状态与减少动态效果滚动。
- 本地浏览器预览被云浏览器 URL 安全策略阻止；上述模拟不覆盖像素渲染、真实软键盘、GPU 性能或 Safari 合成。真实 iPhone 项目仍待执行。

- 部署后 Chromium 已目视确认首页灰板消失、浅深色材质与清晰卡片；搜索 `IMAX` 有结果，× 关闭后解除背景 inert 且焦点回到触发按钮。发现悬停后首次点击会反向关闭菜单、深色首页标题低对比，已作为浏览器验收补修。渐变工具原先 32px 高的实心滑杆改为 44px 触控区内的 6px 轨道，工具副标题也跟随主题色。iPhone 仍未真机验证。
