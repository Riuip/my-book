# iPhone Safari / Chromium 验收清单

背景：PR #55 遗留 Apple 图标缺失，PR #56 未做视觉与真实 iPhone 验证。图标已补齐；最新设计按用户反馈改为[黑白简约界面](minimal-design.md)，已停用 SVG 折射和按钮弹性，仅导航使用 CSS 模糊。以下复选框留给真实 iPhone，不能由 Chromium 窄屏预览代勾。

| 优先级 | 页面 / 操作 | 通过标准 |
|---|---|---|
| P0 ☐ | 首页、文章：上下滚动，开关文章/实验菜单，横竖屏 | 导航轻薄、无厚白边；菜单完整可点，安全区不遮挡；正文、图片、标题不横向溢出；进度条随阅读变化。 |
| P0 ☐ | 搜索 IMAX：开关键盘、清空、进入文章后返回 | iPhone 使用搜索页，输入不意外缩放；结果/清空可点。桌面弹窗 × / Escape / 遮罩关闭，焦点返回触发按钮。 |
| P0 ☐ | 渐变、Markdown、番茄钟：拖动、输入、切换、开始/暂停/重置 | 控件不会粘住或误触；窄屏布局清楚；倒计时准确，深浅色选中态可辨。 |
| P1 ☐ | 天气城市切换、Markdown 换主题后导出 | 预览与图片内容一致；请求失败有反馈；导出图不包含导航装饰。 |
| P1 ☐ | 首页/长文/工具：深浅色、减少动态效果、降低透明度、后台恢复 | 无白闪或文字丢失；浏览器暴露系统偏好时导航正确回退；禁用模糊仍可读。 |
| P1 ☐ | 旧标签刷新、添加到主屏幕、离线重开缓存页面 | 加载 edition.css?v=3 / edition.js?v=3 / liquid-optics.js?v=5；缓存 wyq-v18-2026-09-12-pelican；180px WYQ 图标完整。 |

已进行 Chromium 旧版/Fieldnotes 的桌面及 320/390px 预览，验证搜索、菜单、倒计时、Markdown 编辑与导出成功提示、天气城市更新。PR #64 简约版已完成桌面/320/390px、深色菜单、搜索焦点、长文、分类、倒计时和 Markdown 导出成功反馈复验。真实 iPhone Safari 与最终下载图片像素仍需设备验收。
