# 文章阅读界面与首页精简

按圈选附件移除首页顶部「WYQ 的个人空间」、三张文章卡片摘要、工具卡片说明和鹈鹕下方「出发，去探索。」。同时调整模板和动态输出，避免索引更新后重新生成被移除的内容。文章正文和搜索索引摘要保留。

文章页采用统一标题区、正文列和桌面粘性目录；900px 以下目录位于正文前，脚本加载后默认折叠。目录链接在构建时写入 HTML，无 JavaScript 时仍可使用。统一章节间距、代码字体、引用块、表格横向滚动、相关文章和前后篇入口。手机工具入口改为两列，减少首页长度。

## 已修复

- 首页文章链接未变化时，标题、日期等内容不随索引更新。
- 首页动画部分节点缺失时，空节点调用导致后续脚本中断。
- 目录在小屏幕完全不可见；定位高亮混用 offsetTop 与页面坐标。
- 目录点击不更新 URL 锚点；新增焦点定位与当前章节语义。
- 阅读进度把评论、推荐和页脚长度计入正文；改为按正文范围计算，并随内容尺寸变化更新。
- `g t` 分类快捷键被单键主题切换提前处理；滚动快捷键现在遵守减少动态效果偏好。
- 搜索高亮未转义正文 HTML，多关键词可再次匹配先前插入的 mark 标签。
- 代码复制权限拒绝时缺少降级，旧复制接口失败时仍显示成功。

共享资源引用与 Service Worker 缓存版本一并更新。构建脚本可重复运行，生成 22 个页面。

## 验证

- 全部独立 JavaScript 文件和 HTML 内联脚本语法检查。
- 22 个页面无重复 ID、无缺失的本地资源/页面链接；文章目录目标存在。
- 8 篇文章与文章模板的正文文本与原版一致。
- 连续构建输出一致；`git diff --check` 通过。
- `node tools/test-base64.cjs` 通过。
- DOM 回归：同链接文章更新、圈选节点移除、搜索与 HTML 转义/多关键词高亮、手机目录折叠/展开、目录锚点、主题切换、`g t`、复制失败反馈。

DOM 回归依赖 linkedom，可在测试环境安装后运行：

```sh
npm install --no-save --package-lock=false linkedom
node tools/test-reading-ui.cjs
```
